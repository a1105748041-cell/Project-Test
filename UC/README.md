# UC宣讲项目

## 项目简介

UC宣讲项目是一个交互式的加州大学(UC)信息展示平台，通过地图可视化方式展示各UC校区的申请数据、录取信息、专业特点等详细内容。项目旨在为申请者和教育顾问提供直观、全面的UC系统学校信息，辅助做出更明智的申请决策。

## 功能特点

### 1. 交互式地图展示
- 直观展示加州大学各校区在加州的地理位置
- 点击学校图标显示详细信息卡片
- 平滑的动画效果和交互反馈

### 2. 学校详细信息
- 录取数据统计（总申请人数、国际生申请情况）
- 学校排名信息
- 官网链接
- 热门/强势专业展示

### 3. UCSD特色学院系统
- 8个本科学院的详细介绍（创建年份、核心理念、特点）
- 学院制度说明（通识教育要求、住宿区域、社群文化、专业选择）
- 学院对比信息
- 学术部门与本科学院的区别说明

### 4. 公共信息区域
- 国际学生统计数据表格
- 时间线展示重要申请节点
- 动画效果提升用户体验

### 5. 响应式设计
- 适配不同屏幕尺寸
- 移动端友好的界面布局
- 侧边栏交互优化

## 项目结构

```
├── index.html          # 主页面
├── uc-map.js           # 主要JavaScript代码
├── uc-map.css          # 样式文件
├── uc-campuses-updated.geojson  # 学校数据GeoJSON文件
├── imgs/               # 图片资源文件夹
│   ├── UCB.jpeg        # 各学校主图
│   ├── UCLA.jpg
│   ├── UCSD.jpeg
│   └── ...             # 其他学校图片和数据图表
└── README.md           # 项目说明文档
```

## 技术栈

- **前端基础**: HTML5, CSS3, JavaScript ES6+
- **地图可视化**: 自定义地图实现
- **样式设计**: CSS3 (包含动画、响应式设计)
- **数据格式**: GeoJSON
- **图片优化**: 懒加载技术
- **本地服务**: Python HTTP Server

## 安装与运行

### 前置要求
- Python 3.x (用于启动本地服务器)
- 现代浏览器 (Chrome, Firefox, Safari, Edge等)

### 运行步骤

1. 克隆或下载项目文件到本地

2. 进入项目目录
   ```bash
   cd /Users/eliot/Desktop/工作相关/UC宣讲
   ```

3. 启动本地HTTP服务器
   ```bash
   python3 -m http.server 8000
   ```

4. 在浏览器中打开
   ```
   http://localhost:8000
   ```

## 文件说明

### 核心文件
- **index.html**: 页面主结构，包含地图容器和信息面板
- **uc-map.js**: 实现地图交互、数据加载、信息卡片生成等核心功能
- **uc-map.css**: 定义页面样式、动画效果和响应式布局
- **uc-campuses-updated.geojson**: 存储所有UC学校的数据信息（位置、申请数据、学院信息等）

### 资源文件
- **imgs/**: 包含各学校的主图片和数据图表图片
  - 学校主图 (如UCB.jpeg, UCLA.jpg等)
  - GPA统计图表 (如UCBGPA.png)
  - 录取数据图表 (如UCB录取.png, UCB录取率.png)
