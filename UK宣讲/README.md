# 英国名校互动地图项目

这个项目是一个基于Leaflet地图库的互动地图，展示英国四所顶尖大学的信息：圣安德鲁斯大学、杜伦大学、伦敦大学学院(UCL)和布里斯托大学。

## 项目结构

- `uk map.html`: 主HTML文件，包含地图初始化和交互逻辑
- `uk-map.css`: 样式文件，定义地图和侧边栏的外观
- `uk-universities.geojson`: GeoJSON文件，包含四所大学的地理坐标和详细信息
- `imgs/`: 图片文件夹，用于存放学校logo和相关图片

## 功能特点

1. **互动地图**: 点击地图上的标记查看学校详细信息
2. **悬停预览**: 鼠标悬停在标记上显示简要信息
3. **侧边栏详情**: 点击标记后在侧边栏显示学校完整信息
4. **响应式设计**: 适应不同屏幕大小

## 使用方法

1. 将项目文件部署到Web服务器上
2. 在`imgs`文件夹中添加四所大学的图片，文件命名应为：
   - `st-andrews.png` (圣安德鲁斯大学)
   - `durham.png` (杜伦大学)
   - `ucl.png` (伦敦大学学院)
   - `bristol.png` (布里斯托大学)
3. 打开`uk map.html`文件在浏览器中查看

## 数据说明

项目包含以下四所大学的信息：
- 圣安德鲁斯大学 (2026 Times第2名)
- 杜伦大学 (2026 Times第3名)
- 伦敦大学学院(UCL) (2026 Times第9名)
- 布里斯托大学 (2026 Times第10名)

每个学校的信息包括：名称、学生数量、国际生数量、排名、官方网站、图片路径、学费和热门专业。

## 技术依赖

- [Leaflet](https://leafletjs.com/) - 开源的交互式地图库
- [OpenStreetMap](https://www.openstreetmap.org/) - 地图瓦片服务

## 自定义指南

如果需要添加更多大学或修改现有信息，请编辑`uk-universities.geojson`文件。
如果需要更改界面样式，请修改`uk-map.css`文件。
